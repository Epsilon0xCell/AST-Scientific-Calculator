AST-Scientific-Calculator

A command-line calculator that parses expressions with the ast module and never uses eval().

What this is

I built this because eval() will run whatever it is handed. My calculator reads an expression with the ast module first, so the input becomes a tree I can inspect before anything runs.

I only walk nodes I named on purpose. The FUNCTIONS table in calculator.py lists sqrt, sin, cos, tan, log, log2, log10, ln, exp, abs, floor, ceil, round, min, and max. The OPERATORS table lists seven operators. Anything else gets refused by name.

It runs two ways. With no argument it opens a REPL with help, history, and an ans value that holds the last result. With an argument it prints one result and exits.

The tree, drawn out

Run it

python3 calculator.py                # interactive REPL
python3 calculator.py "sqrt(144) + 2 * pi"   # one-shot

Real output from my run of that one-shot command: 

18.2831853072

In the REPL, 2+2 and sqrt(16) both print = 4, and quit leaves cleanly.

Honest notes

The evaluator is recursive because the tree is recursive. A chain with thousands of terms used to die with a RecursionError traceback. It now ends with a plain line I can quote: Error: expression nested too deeply. In the code the message reads "expression is nested too deeply" and the REPL prints it after "error: ".

Whole floats print as whole numbers. I print 4, not 4.0. Other results are capped at 12 significant digits in format_result.
